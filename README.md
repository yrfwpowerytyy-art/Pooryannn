# Pooryannn — Remotion video project

A vertical 1080×1920 Persian motion-graphics short built with Remotion.

## Composition

- Composition ID: `ColdEarth`
- Duration: 35 seconds
- Frame rate: 30 fps
- Output: H.264 MP4, 1080×1920

## Run

```bash
npm install
npm run preview
```

## Render

```bash
npm run render
```

The rendered file is written to `out/cold-earth.mp4`.

## Add narration

The current composition is a visual draft and does not yet include a narration track. When the final Persian MP3 is available, place it in `public/narration.mp3`; the Remotion composition can then be updated to sync scene timing and subtitles to that exact recording.
