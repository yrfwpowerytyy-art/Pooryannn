# Pooryannn — Remotion video project

A vertical 1080×1920 Persian motion-graphics short built with Remotion.

## Composition

- Composition ID: `ColdEarth`
- Duration: 68 seconds (2040 frames at 30 fps)
- Output: H.264 MP4, 1080×1920
- Visual direction: natural city/building colors, warm storefront details, varied winter clothing, visible human characters, and a bright snowy palette rather than a monotonous navy treatment.

## Narration

The previous narration file was located in the user's earlier repository at:

`public/audio/narration.mp3`

The composition references that public MP3 directly. The current scene beats are timed across the approximate 68-second narration duration; exact word-level cue alignment still needs a render/listen pass.

## Run

```bash
npm install
npm run preview
```

## Render

```bash
npm run render
```

The rendered file is written to `out/cold-earth.mp4`.
